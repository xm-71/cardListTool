# Active Deck and Deck Case Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The player always has one active deck; Duel and Gym start with it, and a Deck Case screen picks it.

**Architecture:** A pure module (`game/deckCase.ts`) decides the active deck and builds the Deck Case boxes. The profile stores `activeDeck`. A new `deckcase` route (with a `returnTo` in `useNav`) renders the screen; Duel and Gym setup swap their deck tiles for a small panel with a Change button.

**Tech Stack:** React 19, Zustand, Tailwind 4, vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-13-deck-case-design.md`

## Global Constraints

- Run tests from `apps/web`: `pnpm --filter @ptcg/web test -- <file>` (vitest), e2e with `PW_CHROMIUM=/opt/pw-browsers/chromium-1194/chrome-linux/chrome`.
- Retro style: reuse `Box`, `Button`, `Sheet`, `ScreenFrame`, `RunDeckView`, `FormatBadge`; text ≥ 7px; no sideways scroll at 390 px.
- `activeDeck: string | null` is an owned premade id or `custom:<id>`. Existing saves load with `null`.
- Copy is exact: "This deck can only be used in Gym Challenge", "Build your own decks in the Deck Builder.", "Use this deck", "Active deck", "Choose this deck", "Copy to edit", custom copy name `<deck> copy`, problem text "Not a legal deck: 52 / 60 cards" (first line of `validateCustomDeck`, prefixed "Not a legal deck: ").
- Collector mode closes `deckcase` (add to `BATTLE_ROUTES`); the Trainer Card Deck Case button is hidden there.
- Bots, Frontier and a locked Elite run deck are unchanged. `DeckChoice` stays for hotseat player 2 only.
- No new deck is added, so CLAUDE.md's bot-pool rule is not triggered.

## Review Focus

- The saved active deck is deleted, no longer valid, or unowned: setup and Deck Case quietly use the fallback and show it as ACTIVE.
- A Gym-only custom deck is active and the player opens Duel: notice shown, Play disabled, Change works.
- Back from the Deck Case and "Use this deck" both return to the screen that opened it (Duel, Gym, My House, Deck Builder), including after a reload-less second visit.
- Hotseat: player 2 keeps the tile picker over all premade + valid custom decks; player 1 uses the active deck.
- Existing tests that tap deck tiles in Duel/Gym still pass once they set `activeDeck` instead.

### Task 1: Active deck logic and profile

**Files:**
- Create: `apps/web/src/game/deckCase.ts`
- Modify: `apps/web/src/profile/types.ts` (add `activeDeck`), `apps/web/src/profile/useProfile.ts` (`setActiveDeck`, `finishIntro`)
- Test: `apps/web/test/deck-case.test.ts`, `apps/web/test/profile-active-deck.test.ts`

**Interfaces:**
- Produces:
  - `Profile.activeDeck: string | null` (`newProfile()` → `null`).
  - `type Format = 'standard' | 'gym'`; `interface CaseEntry { id: string; name: string; cover: string; type: string; kind: DeckSource['kind']; format?: Format; problem: string | null; active: boolean }` (`type` is the DeckSource/DeckInfo energy type; for custom decks use the type of its most common energy or the first Pokémon's type — reuse whatever `DeckChoice` shows for custom decks).
  - `deckProblem(deck: CustomDeck, collection): string | null` — first `validateGymDeck` problem, else null; plus `playableIn(deck, collection): { standard: boolean; gym: boolean }` (standard = `validateCustomDeck` empty, gym = `validateGymDeck` empty).
  - `resolveActiveDeck(profile: Profile): string | null` — saved `activeDeck` if an owned premade id or a custom deck usable in Gym (`playableIn().gym`); else `starterDeck` if owned; else `ownedDecks[0]`; else `null`.
  - `caseEntries(profile): CaseEntry[]` — owned premade, then custom; custom has `format = deckFormat`, `problem` = "Not a legal deck: " + first problem when not Gym-playable; `active` marks `resolveActiveDeck`.
  - `type CaseFilter = 'all' | 'premade' | 'custom' | string` (an energy type); `filterEntries(entries, filter)`; `caseFilters(entries): string[]` (All, each type present, Premade, Custom — Custom omitted when no custom entries).
  - `useProfile().setActiveDeck(id: string): Promise<void>` — no-op for ids that are not an owned premade or an existing custom `custom:<id>`.
