# Retro UI, Title Screen and Pack Animations — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**

- Restyle every screen in a Game Boy TCG–inspired retro look.
- Add a title screen, a first-launch intro, a main menu and an Options screen.
- Animate pack opening, with effects that grow with rarity and generated chiptune sound.

**Architecture:**

- A small retro UI kit (`apps/web/src/ui/retro/`) over CSS-variable theme tokens.
- A Zustand `useNav` route store replaces today's tab state.
- `useSettings` keeps the sound preference in localStorage.
- A Web Audio synth (`src/audio/sfx.ts`) plays the sound effects.
- `PackOpening` becomes a phase state machine.
- The profile gains `playerName`, `starterDeck` and `introDone`.
- Only `apps/web` changes.

**Tech Stack:**

- Already in use: React 19, Tailwind 4, Zustand 5, Vitest + Testing Library, Playwright.
- New dependencies: `@fontsource/press-start-2p` and `@fontsource/vt323`.

**Spec:** `docs/superpowers/specs/2026-10-08-retro-ui-design.md`

## Global Constraints

- **Palette:** defined as CSS variables in `src/index.css` only:
  - `--cream #f8f0d0`, `--paper #fffbe8`, `--ink #283040`;
  - `--red #d84848`, `--blue #3868c0`, `--yellow #f0c030`, `--green #58a050`, `--purple #8060c0`;
  - play-mat stripes `#cfe0b0` / `#c4d8a4`.
- **Fonts:** "Press Start 2P" for headings, menus and buttons; "VT323" for card text, the log and dialogue. Both are bundled via `@fontsource`, so the game loads no font from a CDN.
- **Card images:** shown unchanged inside retro frames, never pixelated.
- **Sound:**
  - Web Audio only, with no audio files.
  - No sound before the first user gesture.
  - Every sfx call is a no-op when muted, when `AudioContext` is missing, or when it throws.
- **Reduced motion:** with `prefers-reduced-motion: reduce`, there is no shake, tear or screen flash, and flips become fades.
- **Behaviour:** game, economy and engine behaviour do not change. Every existing user-visible feature is still reachable.
- **Intro defaults:** name of 1–10 characters, default `"PLAYER"`; the starter deck is one of `mega-gengar | mega-diancie | mega-lucario`.
- **Menu:** Duel · Shop · Binder · Decks · Options. Every non-menu screen has a "◀ Back" button with the accessible name "Back".

## Review Focus

1. **Returning M4 player:**
   - Input: a stored profile without the new fields.
   - Expected: they see the intro once, and their credits, cards and decks are unchanged. Covered in Task 3.
2. **Audio unavailable or blocked:**
   - Input: `AudioContext` is missing, its constructor throws, or it is suspended.
   - Expected: everything works silently with no console errors. Covered in Task 2.
3. **Keyboard focus leaks:**
   - Input: typing in the intro name field or the deck builder, or arrow keys on the board.
   - Expected: the title's "any key" and the menu cursor don't react. Covered in Tasks 1 and 4.
4. **Leaving the pack opening mid-animation:**
   - Input: "Reveal all", "Done" or navigating away while timers are pending.
   - Expected: no errors and no state updates after unmount. Covered in Task 6.
5. **Phone width (375 px):**
   - Expected: title, menu, intro, Shop, pack opening and board have no horizontal page scroll. Covered in Task 8.

### Task 2: Settings and sound effects

**Files:** Create `src/settings/useSettings.ts`, `src/audio/sfx.ts`. Test: `test/sfx.test.ts`.

**Interfaces (Produces):**

- `useSettings`: a Zustand store `{ sound: boolean; setSound(on: boolean): void }`.
  - It loads from localStorage key `ptcg.settings` and defaults to `{ sound: true }`.
  - It writes on change.
  - All reads and writes are wrapped in try/catch.
- `type Sfx = 'cursor'|'confirm'|'back'|'shake'|'tear'|'flip'|'rare'|'ultra'|'special'|'win'|'lose'`
- `sfx(name: Sfx): void`:
  - creates one `AudioContext` lazily on first call;
  - does nothing if `!useSettings.getState().sound`, if the context is unavailable, or if construction throws;
  - each effect is a short sequence of square/triangle oscillator notes, or a noise buffer for `tear`.
- `unlockAudio(): void`: called on the first pointerdown/keydown (registered once in `main.tsx`); resumes the context.

- [ ] **Step 1: Failing tests.**
  - With no `AudioContext` on `window`, `sfx('flip')` doesn't throw (RF2).
  - With a stub `AudioContext` whose constructor throws, `sfx` doesn't throw and logs nothing (RF2).
  - With a recording stub, `sfx('flip')` creates an oscillator; with `sound` false it creates none.
  - `setSound(false)` persists, and a fresh module load reads `false`.
  - A localStorage that throws gives the default `{ sound: true }` without throwing.
- [ ] **Step 2:** Run `pnpm --filter @ptcg/web test -- sfx`. Expected: FAIL.

### Task 6: Animated pack opening

**Files:** Create `src/ui/pack/rarity.ts` and `src/ui/pack/Pack.tsx` (the CSS-drawn wrapper); rewrite `src/ui/PackOpening.tsx`; add keyframes to `src/index.css`. Test: `test/pack.test.tsx`.

**Interfaces:**

- `type Tier = 'common'|'rare'|'ultra'|'special'`
- `rarityTier(rarity: string): Tier`:
  - Common and Uncommon → `common`;
  - Rare → `rare`;
  - Double rare and Ultra Rare → `ultra`;
  - Illustration rare, Special illustration rare and Mega Hyper Rare → `special`;
  - anything else → `common`.
- `TAG: Record<Tier, string | null>`:
  - `common`: null;
  - `rare`: "RARE!";
  - `ultra`: the uppercase rarity + "!" (e.g. "ULTRA RARE!");
  - `special`: likewise (e.g. "SPECIAL ILLUSTRATION RARE!").
- `PackOpening({ setId, cards, onDone })`: the Shop passes `setId` as well.
  - The phase sequence is `'shake' (600 ms) → 'tear' (400 ms) → 'stack' → 'all'`. In the stack phase, `shown` counts the flipped cards.
  - Next, a click on the stack, Enter or Space flips one card and plays `sfx('flip')`, then the tier's sfx (`rare`, `ultra` or `special`).
  - A `special` card renders `data-testid="flash"` for 300 ms. Tiers `ultra` and `special` render sparkles and the tag.
  - "Reveal all" sets the phase to `'all'` and plays `sfx('rare')` once.
  - With reduced motion (`matchMedia('(prefers-reduced-motion: reduce)')`), it starts at `'stack'` and renders no flash.
  - All timers are cleared on unmount.

  - The shake phase shows the pack; after 1000 ms the stack shows "Card 0 of 10" and Next.
  - Next shows card 1's image.
  - A pack whose first card is a Special illustration rare shows the flash and the "SPECIAL ILLUSTRATION RARE!" tag after the first flip.
  - "Reveal all" shows 10 images and Done.
  - Reduced motion (stubbed `matchMedia`) starts at the stack.
  - **(RF4)** Unmounting during the shake phase, then advancing timers, logs no React warnings.
  - Update the existing Shop test for the new phases: wait for "Card 0 of 10", then Next shows "Card 1 of 10".

  - `sparkle`: scale and fade;
  - `flash`: a white overlay fading out;
  - `foil`: a hue-rotate sweep.
