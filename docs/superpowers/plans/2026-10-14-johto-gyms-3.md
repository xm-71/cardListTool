# Johto Gym Challenge, part 3 (Elite Four, Champion Lance, Red) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After eight Johto badges the player can run the Johto Elite Four (Will, Koga, Bruno, Karen) and Champion Lance with one locked deck; beating Lance records a Johto Hall of Fame entry and unlocks Red, an optional extra fight.

**Architecture:** The Kanto Elite run machinery in `gym.ts` becomes region-aware (`EliteRun.region`, `HallOfFameEntry.region`, match context `region`) with Kanto as the default for old saves; the profile, match start, game-over and Gym Challenge screen read the region from the run or context. Five new Gym decks (cards package) and, in 3b, Red's deck and `redBeaten` flag. Two PRs: **3a** = Tasks 1–9, **3b** = Tasks 10–12.

**Tech Stack:** TypeScript, React 19, Zustand, vitest + Testing Library, Playwright, pnpm monorepo (`apps/web`, `packages/{engine,cards,economy,bots}`).

**Spec:** `docs/superpowers/specs/2026-10-14-johto-gyms-3-design.md`

## Global Constraints

- Gym decks: 60 cards, ≤ 4 copies per name (basic Energy aside), ≤ 1 ACE SPEC, Gym-legal (mark H or later, or any sv03.5 card); `assertGymDeck(deck)` in `packages/cards/test/helpers.ts` enforces it.
- Cards whose effect needs engine support that does not exist are left out and replaced; **no engine changes**. Every omission is a `Ruling:` in the ledger.
- Medium-piloted win rate against the premade decks (Easy-piloted) 40–65% (round-robin); bands: Will/Koga/Bruno/Karen `[40, 60]`, Lance and Red `[45, 65]`.
- All five Elite/Champion bots and Red use difficulty `'hard'`; Lance plays one fixed deck (no counter-pick).
- Ids: `will`, `johto-koga`, `johto-bruno`, `karen`, `johto-lance`, `red`; display names "Will", "Koga", "Bruno", "Karen", "Champion Lance", "Red".
- Rewards: no per-match Elite reward. Johto Champion first win `1500 credits + 3 me02 packs`, later `400 credits + 1 me02 pack`. Red: first win `2000 credits + 3 me02 packs` (`redBeaten`), later wins normal credits.
- Old saves: a run without `region` and a Hall of Fame entry without `region` are Kanto's. Kanto behaviour, rewards and saves do not change.
- New decks must also be available to bots (CLAUDE.md): `GYM_DECKS`, `packages/bots` `scripts/round-robin.ts` (`GYM_TARGETS`), `test/gym-fuzz.test.ts` and `test/fuzz.test.ts` counts, economy `gym-decks.test.ts` `EXPECTED_DECKS`. Gym decks stay out of `DECKS`. Gym deck count: 23 → 28 after Task 5 → 29 after Task 10.
- After `import-cards` (network): `pnpm exec prettier --write packages/cards/src/data/cards.json` and `git checkout packages/cards/src/sets.json`. Use absolute paths; never `cd ..`.
- Commit trailers per the session attribution reminder.

## Review Focus

1. A Johto Hall of Fame entry must **not** unlock Johto or flip the town's champion flag (`kantoChampion`); a Kanto entry still does. Old entries without `region` count as Kanto.
2. One run at a time across regions: starting a Johto run while a Kanto run exists (and vice versa) changes nothing, and the other region's panel says "Finish your {region} run first."
3. A result for the right stage but the wrong region (Johto match result arriving while the run is Kanto's, same stage number) is stale and changes nothing.
4. Reward packs from `me02`: the game-over dialog currently hard-codes set `sv03.5` and the text "Scarlet & Violet 151 pack" (found while planning; a part-1 gap) — Johto badge and Champion packs must show the right set and wording.
5. Reload or quit mid-match ends a Johto run too (`abandonUnfinishedRun`); first Johto Champion win pays 1500/3, a second pays 400/1, independent of the Kanto Hall of Fame; Kanto Blue still counter-picks while Lance does not.
