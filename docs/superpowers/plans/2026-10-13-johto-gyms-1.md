# Johto Gym Challenge, Part 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Johto region in Gym Challenge, unlocked by the Kanto Champion, with the first four leaders (Falkner, Bugsy, Whitney, Morty) and their rewards.

**Architecture:** Four new Gym decks (card JSON, imported cards, card scripts) go into `GYM_DECKS`. `gym.ts` gains a `Region` model over the same `gym.badges` list, region-aware order rules and a Johto reward (credits + a `me02` pack). `GymChallenge` gets Kanto/Johto tabs.

**Tech Stack:** TypeScript, React 19, Zustand, vitest + Testing Library, Playwright; `@ptcg/cards` card scripts, `@ptcg/bots` fuzz tests.

**Spec:** `docs/superpowers/specs/2026-10-13-johto-gyms-1-design.md` (spec deviation, ruled here: `JOHTO_LEADERS` has the 4 built leaders; the four later ones are a `JOHTO_UPCOMING` list of `{ id, name, type }` shown as "Coming soon", because `Opponent.deck` must name an existing Gym deck).

## Global Constraints

- Gym-legal cards only: regulation mark H or later, or any `sv03.5` card (mark G cards outside 151 are illegal: Falkner's Supporter, Pidgeot ex sv03, Natu/Xatu). Decks are exactly 60 cards, ≤ 4 copies per name (basic Energy aside), ≤ 1 ACE SPEC.
- Bots: Falkner and Bugsy `difficulty: 'medium'`; Whitney and Morty `difficulty: 'hard'`.
- Badges: Falkner "Zephyr", Bugsy "Hive", Whitney "Plain", Morty "Fog". Types: Flying, Bug, Normal, Psychic (display strings).
- Johto reward for leader index `i`: `150 + 25 * i` credits and 1 pack from `JOHTO_PACK_SET = 'me02'`; Kanto rewards unchanged (151 pack). Rematches pay the normal bot credits.
- Johto is open when `gym.hallOfFame.length > 0`; locked text: "Beat the Kanto Champion to travel to Johto."; later tiles: "Coming soon".
- Kanto behaviour, the Trainer Card and the town badge flag (x / 8) stay Kanto-only; `canStartElite` counts Kanto badges only.
- CLAUDE.md: every new Gym deck goes into `packages/bots` `test/gym-fuzz.test.ts`, `test/fuzz.test.ts` and `scripts/round-robin.ts`. Gym decks are not added to `DECKS`.
- Run tests from the repo root: `pnpm --filter @ptcg/cards exec vitest run <file>`, `pnpm --filter @ptcg/bots exec vitest run <file>`, `pnpm --filter @ptcg/web exec vitest run <file>`. Imports need network: `pnpm --filter @ptcg/cards import-cards` (re-run after any new card appears in a deck JSON).

## Review Focus

- A save with Johto badges but fewer than 8 Kanto badges: `canStartElite`, `nextGymIndex(Kanto)`, `townStatus` and `normalizeGym` must ignore or keep Johto ids correctly (Task 5).
- Rematching a beaten Johto leader pays normal credits only and no badge reward or `me02` pack (Task 6).
- A Hall of Fame entry unlocks Johto for an existing save at once; without one the Johto badge case is not shown (Task 7).
- A card in a Gym deck with no script crashes the bot's game: every card of every Gym deck is playable (Task 1–4, `decks` test).
- Leader lookups by id (game over screen, describe, match start) work for Johto ids, not only Kanto (Task 6).

### Task 5: Region model, Johto leaders and rewards

**Files:**
- Modify: `apps/web/src/game/gym.ts`
- Test: `apps/web/test/johto-progress.test.ts`

**Interfaces:**
- Consumes: `GYM_DECKS` ids `falkner | bugsy | whitney | morty` (Tasks 1–4).
- Produces (all exported from `gym.ts`):
  - `type Region = 'kanto' | 'johto'`; `JOHTO_LEADERS: readonly Opponent[]` (falkner, bugsy, whitney, morty in order, with intro/win/lose text in the Kanto style); `JOHTO_UPCOMING: readonly { id: string; name: string; type: string }[]` (chuck Fighting, jasmine Metal, pryce Water, clair Dragon); `JOHTO_TOTAL = 8`.
  - `leadersOf(region: Region): readonly Opponent[]`; `findLeader(id: string): Opponent | undefined` (searches both); `regionOf(id: string): Region | null`.
  - `nextGymIndex(badges, leaders = LEADERS)`, `gymStatus(badges, leaderId)` and `canChallenge(badges, leaderId)` find the leader's region themselves; `canStartElite(badges)` counts Kanto only.
  - `johtoUnlocked(g: GymProgress): boolean` (`g.hallOfFame.length > 0`).
  - `JOHTO_PACK_SET = 'me02'`; `Payout` gains `set?: string`; `johtoBadgeReward(index: number): Payout` (`{ credits: 150 + 25 * index, packs: 1, set: JOHTO_PACK_SET }`).
